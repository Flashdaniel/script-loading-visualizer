🏆 Key Takeaway from the Race

🥇 Defer & Module

Fastest First Render! HTML parsing finishes with zero pauses. The user sees the full page in record time.

🥈 Async

Good for independent scripts. Downloads in background, but briefly halts the parser the instant it finishes downloading.

🐢 Normal (Head)

Major bottleneck! Freezes parsing entirely while fetching. Leaves visitors staring at a blank screen.

Quick Reference: The 4 Script Strategies

A handy cheatsheet for architecting fast, modern web applications.

Strategy Network Download When Execution Runs Execution Order Blocks HTML Parser? Recommended For
Normal <script src="..."> Synchronous (when found) Immediately after fetch Sequential in order Blocks completely Critical polyfills needed before any HTML renders
Async <script async src="..."> Parallel in background As soon as downloaded First-to-finish (Race condition) Blocks when executing Independent tools: Google Analytics, Ads, Sentry
Defer <script defer src="..."> Parallel in background After HTML parsing, before DCL Document order preserved Zero download block Main application code, UI widgets, DOM-dependent libraries
Module <script type="module" src="..."> Module graph in parallel Deferred by default Dependency order preserved Zero download block Modern ES modules, Vite / Webpack output bundles
